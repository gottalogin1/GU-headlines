Source health

How each news site the worker reads is doing right now (not only in the period above). Failing: its latest check went wrong. Quiet: its checks work, but it has had no new story for longer than the "Quiet after" time. That time is twice its longest wait between two stories in the two months before its newest story, and at least 2 days (at least 30 days for a site with fewer than 5 stories in those two months). A quiet site's feed or pages may have changed, or it may have stopped posting. {% if settings.discord_webhook_url %}A site that fails for {{ settings.alert_after_hours }} hours, or goes quiet, is posted in Discord.{% else %}Discord alerts are off (DISCORD_WEBHOOK_URL is empty).{% endif %}

Backups

{% if settings.backup_time %}Every night at {{ backup_time_text }} (Guam time), the server backs up the whole site: the database, the photos, your settings (.env), the config folder and the https certificates, and the mailboxes when your own mail server is on. Each backup is kept for {{ settings.backup_keep_days }} days, in the backups/site folder on the server.{% else %}Nightly backups are off (BACKUP_TIME is empty in .env). To back up by hand, run ./scripts/site-backup.sh now on the server.{% endif %} A download is one .tar file with everything in it. It holds your passwords and your readers' email addresses, so keep it private. To put a backup back, copy the file into the GU-headlines folder on the server and run ./scripts/site-backup.sh restore followed by the file's name.
